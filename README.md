# Space Portal Hub

一个用于归档和发布多个独立 HTML 页面的仓库。此处存放的页面彼此独立，不依赖特定后端服务，适合用于保存静态内容或提供轻量级信息展示。

## 项目简介

本仓库旨在整理和托管一组自包含的 HTML 页面。这些页面可能涵盖不同的主题或功能，但都以纯前端方式实现，便于直接访问、分享或存档。仓库本身不绑定任何特定网站或域名，仅作为页面集合的发布入口。

## 目录说明

```
├── pages/           # 存放所有独立 HTML 页面
├── assets/          # 页面共用的资源文件（如 CSS、JS、图片等）
├── index.html       # 仓库首页（可选，用于导航或说明）
└── README.md        # 本文件
```

- `pages/` 目录下每个子文件夹或文件代表一个独立的 HTML 页面，命名清晰以反映其内容。
- `assets/` 目录存放页面间共享的静态资源，避免重复引用。

## 页面归档说明

- 每个 HTML 页面均为完整自包含文件，尽量不使用外部依赖（或仅在页面内引用 CDN 资源）。
- 页面内容可能随时间更新或补充，历史版本可通过 Git 提交记录追溯。
- 本仓库不保证所有页面永久可用，但会尽力保持链接有效和内容稳定。

## 维护说明

- 欢迎提交 Issue 报告页面问题或提出改进建议。
- 如需添加新页面，请遵循以下原则：
  - 将页面放入 `pages/` 对应子目录。
  - 确保页面不包含恶意代码或侵犯他人权益的内容。
  - 提交 Pull Request 时附上简要说明。
- 管理员会定期检查页面兼容性和资源有效性。

## 使用方式

直接通过 GitHub Pages 或其他静态托管服务访问本仓库中的 HTML 文件。例如，在浏览器中打开 `https://<你的用户名>.github.io/space-portal-hub/pages/example-page/` 即可查看对应页面。
